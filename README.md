# 雲科吃什麼

從雲科出發，讓轉盤決定下一餐。以餐點類型、搜尋範圍、預算與表定營業時間篩選斗六餐飲，再透過嵌入的 Google 地圖查看位置與導航。

[開啟網站](https://sandwichcookice.github.io/TAICA-GenAI-Personal-website/) · [產品規格](SPEC.md) · [資料維護](DATA.md) · [驗收紀錄](TESTING.md)

## 使用方式

1. 進入頁面即可看到左側轉盤、下方抽選按鈕與右側 Google 地圖。需要調整時向下捲動。
2. 按「轉一下，決定吃什麼」，查看抽中店名、品項價格、表定時刻與地址。
3. 在地圖查看位置，或使用「帶我去吃」開啟導航。

預設為正餐、大學路以南的龍潭路附近生活圈、預算不限、現在依表定時間營業。「遠一點」包含整個附近範圍，再加入校門步行約 30 分鐘內的已核對店家；「斗六市區」包含完整斗六市行政區。步行起點為 **23.693064, 120.533660**。

缺少相應資料的店家不會進入受限制的候選。沒有候選時，可自行擴大範圍、放寬預算或時間；網站不會自動修改條件。下方名單預設顯示龍潭路附近全部已收錄店家，包含未進入當次候選與待核對店家。

勾選防連續重複後，有兩家以上時會排除上次抽中的店家；只有一家時仍可抽選。名單搜尋只影響下方清單，歷史只保留當次頁面的最近五次抽選。所有人共用相同資料，不儲存個人偏好。

## 本機開啟

直接用瀏覽器開啟 `index.html`，或執行：

```sh
python3 -m http.server 8000
```

開啟 `http://localhost:8000`。HTML、CSS、JavaScript 與公開資料均內嵌於單一檔案，網站執行不需要安裝套件、建置、後端或 API 金鑰。離線時可使用內嵌名單與抽選；Google 地圖及來源連結需連線。

## 開發驗證

Node.js 18 以上：

```sh
npm ci
npm test
```

jsdom 與 Playwright 僅用於開發測試，不載入正式網站。測試涵蓋複合篩選、台灣時區、跨日營業、指定日期、預算邊界、轉盤落點、防重複與互動狀態。另提供 `npm run test:browser`，預設以 `/usr/bin/chromium` 驗證本機 8000 埠；可用 `CHROMIUM_PATH` 與 `SITE_URL` 指定瀏覽器及網站。驗證結果與限制見 [TESTING.md](TESTING.md)。

## GitHub Pages

發布來源為 `main` 分支根目錄，保留 `.nojekyll`。更新 `main` 後由 GitHub Pages 發布；以 Actions 中對應 commit 的部署結果確認版本。

首次設定：Settings → Pages → Deploy from a branch → `main` / `/(root)`。

## 資料與設計

目前收錄 60 家，47 家位於龍潭路附近範圍；29 家具每週表定時刻、9 家具公開路網步行資料、5 家具基準品項價格。資料涵蓋校園周邊、斗六市區與外圍聚落，仍在持續盤點，不宣稱收錄所有店家。價格依已核對的一人份基準品項，不能代表整份菜單；表定時間不代表即時營業；5 家採外送平台供餐時段，結果另行標示，到店前仍須確認。來源、查閱日期與缺項說明見各店資料及 [DATA.md](DATA.md)。
